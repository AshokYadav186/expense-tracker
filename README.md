# 💸 Expense Tracker

A modern full-stack Expense Tracker built using the MERN Stack that helps users efficiently manage their daily expenses, monitor spending habits, visualize expenses through charts, set monthly budgets, and receive AI-powered financial insights.

---

## 🚀 Features

- 📊 Interactive Dashboard
- ➕ Add New Expenses
- ✏️ Edit Existing Expenses
- ❌ Delete Expenses
- 🔍 Filter Expenses by Category
- 💰 Monthly Budget Tracking
- 📈 Category-wise Spending Analysis (Pie Chart)
- 🤖 AI-Powered Spending Insights
- 📱 Responsive User Interface

---

## 🛠 Tech Stack

### Frontend
- React.js
- CSS3
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Charts
- Recharts

### AI
- Gemini API

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/AshokYadav186/expense-tracker.git
```

Install dependencies

### Backend

```bash
cd server
npm install
```

### Frontend

```bash
cd client
npm install
```

Start Backend

```bash
npm run dev
```

Start Frontend

```bash
npm start
```
